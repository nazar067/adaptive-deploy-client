# AdaptiveDeploy Client

React + TypeScript + Vite frontend, Express/TypeScript backend, PostgreSQL. Окрема служба `adaptive-web`, Unix socket для Nginx і приватний HTTP-клієнт до Engine. Без реєстрації; створення адміністратора через `server/admin.ts`. Інструкція для Ubuntu, DNS, TLS, БД та systemd — загальний README.md в архіві AdaptiveDeploy.

```bash
npm install
npm run build
```
